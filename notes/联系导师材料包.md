# 联系导师材料包（本校生专用）

> 目标：让导师在 **30 秒内**判断"这个学生能不能带"。
> 本校生的最大优势：**可以约线下见面**，一封邮件回信率远高于外校学生。

---

## 一、总体节奏（分两阶段，不要一次把话说满）

| 阶段 | 时间 | 发什么 | 目的 |
|---|---|---|---|
| **阶段 1：投石问路** | 现在（2026 年 9–10 月） | 短邮件：自我介绍 + 说明在学什么 + **问是否方便当面请教** | 建立联系，摸清对方有没有意愿/名额 |
| **阶段 2：带着作品再去** | 2026 年 11–12 月 | ECG 项目完成后，发**更新版邮件 + GitHub 链接 + 一页说明** | 从"想学的学生"变成"能干活的人" |

**为什么现在就发第一封？**
- 大学老师邮件极多，**"早联系"本身就是筛选信号**——说明你在认真规划
- 你现在**没有作品**，所以第一封邮件**不要吹牛**，只做一件事：**约一次面谈**
- 面谈后再决定要不要跟——**先见人，再决定，成本最低**

## 三、阶段 1 邮件模板（现在就能发，复制改名字）

```
主题：生物工程2024级本科生 想向您请教（本校生）

X 老师您好，

我是资源加工与生物工程学院生物工程专业 2024 级本科生 XXX，学号 XXXXXXXX，
计划推免到湘雅基础医学院智能医学技术/电子信息方向，对您的 XX 方向很感兴趣。

我目前自学了 Python 科研编程（NumPy / Pandas / Matplotlib），正在学 SciPy 与
生物医学信号处理，目标是在这学期内独立完成一个基于公开心电数据库的分析项目。
我的练习记录放在这里：https://github.com/Mjing-bme/xxx

我知道自己现在基础还很浅，所以想先向您请教三个问题：
1. 您课题组目前主要在做的问题是什么？
2. 像我这样生物工程背景、只做过编程练习的学生，有机会从什么工作入手（比如整理数据、复现论文）？
3. 如果方便，我能否到您办公室当面请教 15 分钟？

我本学期课表如下（择您方便的时间）：
【列出周二下午、周四上午等你不忙的时段】

我的联系方式：电话 1XX-XXXX-XXXX ｜ 邮箱 mjing539breeze@gmail.com

感谢您的时间！
XXX
```

### ⚠️ 三条纪律

1. **不要吹牛。** 你现在确实只有 NumPy 基础——**说实话反而加分**，"基础浅但方向明确"比"什么都懂一点"可信得多
2. **一定要给具体时间。** "您方便时告诉我"= 让对方做决策成本，容易石沉大海。**直接列 2–3 个时段**
3. **不要在邮件里问"我能保研吗"。** 第一次接触谈学术，不谈政策。政策问题问教务办

## 四、阶段 2 邮件（做完 ECG 项目后，11–12 月）

```
主题：ECG 信号处理项目完成，想向您请教（附代码）

X 老师您好，

上次请教后我完成了第一个小项目，向您汇报：

- 数据：PhysioNet MIT-BIH 心律失常数据库
- 做了什么：0.5–40Hz 带通滤波去基线漂移与工频干扰 → R 波检测 → RR 间期提取
  → 计算 HR / SDNN / RMSSD / pNN50 与 LF/HF 频域指标
- 还做了一个对比实验：用 1D CNN 做心律失常分类，并与随机森林基线比较
  （按记录划分数据集，避免数据泄漏）
- 代码与结果图：https://github.com/Mjing-bme/xxx
- 一页说明：见附件

我发现最没搞明白的是【写一个真实困惑，例如"R 波检测在运动伪影段的鲁棒性"】，
想请教您的看法。也想知道这个方向在您课题组是否有进一步做下去的价值。

如果方便，我能否带着结果到您办公室当面汇报？
XXX
```

**这封邮件的杀伤力在于三点**：
1. 有**可验证的东西**（代码 + 图 + 指标），不是"我学过"
2. 主动说了**"按记录划分避免数据泄漏"**——这是懂行的标志，导师一看就知道你认真读过东西
3. 提出**真实的技术困惑**——证明你不是来刷简历的

## 五、一页项目说明模板（附件用，PDF）

导师不会读 10 页的东西。**一页 A4，结构固定**：

```
标题：基于 MIT-BIH 数据库的心电信号处理与心律失常分类初探
姓名 / 专业 / 年级 / 联系方式 / GitHub 链接

1. 问题背景（3 行）
   为什么心电自动分析有意义；现有方法的问题是什么

2. 数据与预处理（4 行）
   数据来源、样本量、采样率；滤波参数与理由（为什么 0.5–40Hz、为什么 50Hz 陷波）

3. 方法（5 行）
   R 波检测原理；提取哪些特征；模型结构（如 1D CNN 的层数、输入长度）

4. 结果（1 张图 + 1 张表）★ 把最好的图和指标表放这里
   混淆矩阵 + F1/敏感度/特异度；与传统方法的对比

5. 不足与下一步（3 行）★ 这一段最能体现科研素养，务必写
   例如："数据仅来自单中心 48 例，未验证跨中心泛化性；
   运动伪影段的 R 波误检率高，下一步计划引入自适应阈值……"

6. 我的困惑 / 想请教的问题（2 行）
```

### 为什么"不足与下一步"最重要

因为**几乎所有本科生都会把结果说得完美**。主动指出自己方法的局限，等于告诉导师：
**这个人知道自己不知道什么**——这是科研的起点，也是导师最想看到的素质。

## 六、面谈时可能被问到的问题（提前准备）

| 问题 | 你要能回答 |
|---|---|
| 你为什么想做这个方向？ | 讲一个真实的动机，不要背"交叉学科前景广阔" |
| 你专业课学过什么？信号与系统学过吗？ | **诚实**。没学过就说没学过，但说"我在自学，学到了 XX" |
| 你这个项目的错误率是多少？为什么这么高？ | 要有具体数字，并**能解释原因** |
| 你平时用什么工具？ | Python / Git / VS Code，别说不会的东西 |
| 你每周能投入多少时间？ | 给**具体且诚实**的数字（如"工作日 1 小时、周末 3 小时"），别夸口 |
| 能保研吗？排名多少？ | 如实说排名区间，**不要隐瞒**（导师能查） |
