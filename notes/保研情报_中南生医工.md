## 四、策略结论（基于"跨专业 + 校内"这个前提）

1. **第一关不是导师，是排名。** 校内推免资格由学院按综合成绩排出名额，**拿不到资格，联系多少导师都没用**。
   → 所以专业课绩点是硬门槛，技能学习不能挤占它。
2. **第二关是"导师愿意要"。** 跨专业学生最大的劣势是"没有科研经历"。你四周计划的最终目的，
   就是把这个劣势换成一个**能当场打开 GitHub 给对方看的项目**。
3. **联系导师的时间窗口**：⬜ 待确认（等推免时间线调研结果）。经验上应在**夏令营/预报名前 1–2 个月**，
   即项目做完、有代码可展示的那一刻就是最佳时机，而不是等到系统开放。
4. **方向选择要"贴脸"**：若黄忠朝等导师确认做生物医学信号/图像处理，那么你第二周学 ECG 处理
   （MIT-BIH、R 波检测、HRV）就是**直接对口的敲门砖**，不是通用练习——这会极大提高联系成功率。
