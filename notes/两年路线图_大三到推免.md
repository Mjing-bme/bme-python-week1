# 两年路线图：大三上 → 推免（2026.10 — 2028.10）

> 适用对象：中南大学生物工程本科生，2024 年入学、2028 年 6 月毕业，目标**跨专业推免到本校湘雅基础医学院**
> （990400 智能医学技术 / 085400 电子信息），首选导师喻罡（心电生理信号 + 病理图像 AI）。
>
> **总原则：绩点排名是第一关，科研经历是第二关，技能是撬动第二关的筹码。**

## 一、大三上（现在 — 2027.1）：地基期

### 1.1 学习主线（四周计划 → 延展成整学期）

| 时间 | 内容 | 目标 |
|---|---|---|
| 第 1–2 周 | NumPy / Pandas / Matplotlib / Git | 能独立分析陌生 CSV |
| 第 3–4 周 | SciPy + 数字信号处理基础 + ECG 实战 | 跑通 MIT-BIH 全流程 |
| 第 5–8 周 | 深度学习入门（PyTorch, 李沐）+ 1D CNN 心律失常分类 | 能训练并解释一个模型 |
| 第 9–16 周 | 拓展项目（二选一） | 见 1.2 |

**每周固定投入**：**6–8 小时**（不要更多）。理由：绩点是第一关，挤占绩点是自杀。
建议节奏：工作日每天 1 小时 + 周末 3 小时。

### 1.2 学期项目（第 9–16 周，二选一，做透一个）

- **路线 A（对口喻罡）**：ECG 心律失常智能分析与可视化系统
  多导联/多记录批量处理 → 特征工程 + 深度学习对比 → 做成能一键跑通、出报告的工具
- **路线 B（对口戴培山/彭宽）**：医学影像分类/分割
  公开数据集（如胸部 X 光、脑 MRI）→ 预处理 → 迁移学习 → 分割/分类 → 结果可视化

> **判断标准**：能不能对导师说"我自己从原始数据做到了结果，代码在这里，你可以跑一下"。

### 1.3 大三上必须同步做的事

- [ ] **四六级**：如果还没过六级，**这学期必须过**（推免材料硬性要求）
- [ ] **绩点**：确认自己现在专业排名第几（去教务系统查，或问教务办）→ 这是最关键的单一数字
- [ ] **信号与系统 / 数字信号处理**：如果学校开课，**认真上**（面试要考，且是核心理论）
- [ ] **建立记录习惯**：每天 Obsidian + 至少一次 Git commit

## 二、大三寒假（2027.1 — 2027.2）：争取进实验室

### 为什么这是最关键的转折点

你现在的最大劣势是**"没有科研经历"**。而解决它只有一个办法：**真的进一个实验室**。
比"自己做几个项目"强十倍——因为导师看重的是**"被指导过、知道科研是怎么回事"**。

### 怎么做

1. **先发邮件，别直接上门**（但本校学生可以约线下）
2. 目标：**2–3 位**，优先级 **喻罡 → 肖嘉莹 → 彭宽**（系内）→ 卡的话再考虑戴培山（计算机学院）
3. 邮件里必须有：**GitHub 链接 + 一页项目说明 + 一句"我能从什么基础工作做起"**
4. 现实预期：导师大概率让你**先跟着学长学姐做数据整理/复现论文**——**接受它，这就是入口**

## 三、大三下（2027.3 — 2027.7）：进组 + 补数学

| 事项 | 说明 |
|---|---|
| **实验室工作** | 每周固定投入，**坚持一学期不要断**（连续性比强度重要）。目标是有一件"自己负责的小事" |
| **数学** | 线性代数（矩阵运算、特征值）、概率统计（分布、假设检验）、微积分。**不用为考试学，要能用** |
| **英语** | 六级刷分（550+ 更好）；开始读英文论文（从综述开始） |
| **技能深化** | 从"会调库"到"懂原理"：FFT、滤波器设计、CNN 反向传播 |

**大三下结束时应该有的东西**：一段可写进简历的科研经历 + 一个能演示的项目 + 一个不错的排名。

### 面试准备清单（专业基础 + 综合素质 + 外语，各 100 分）

- **专业基础**：医学成像原理、信号与系统（采样定理、卷积、傅里叶）、数字信号处理（滤波器）
- **综合素质**：能讲清楚"我做了什么、为什么这么做、失败在哪"
- **外语**：能用英语介绍自己的项目（准备 2 分钟英文自述）

## 八、贯穿全程的四条铁律

1. **绩点排名是第一关。** 拿不到推免资格，项目做得再好也没用。
2. **连续性 > 强度。** 每周 6 小时坚持一年，胜过寒假突击 100 小时。
3. **一切产出沉淀到 GitHub。** 代码、报告、笔记——**可验证的东西才有说服力**。
4. **尽早进实验室。** 自己做的项目和"被导师指导过的科研"在评审眼里不是一个量级。
