## 基础语法 / 知识点
- `np.array(...)` → 把 Python 列表变成 ndarray
- `np.zeros(...)` / `np.ones(...)` → 预分配数组（科研中先占位、后填数）
- `np.arange(起点, 终点, 步长)` → 像 range，但终点取不到
- `np.linspace(起点, 终点, 个数)` → 按"个数"等分，**终点能取到**
- `数组.shape` → 形状，如 (600,) 表示 600 个元素的一维数组
- `数组.ndim` → 维度数（一维=1，二维=2）
- `数组.dtype` → 元素类型（float64 / int64）
- `数组.size` → 元素总数
- 概念：**向量化** = 对整个数组一次性运算，不写 for 循环
